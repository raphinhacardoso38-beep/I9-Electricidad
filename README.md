## Sobre el proyecto

Sitio web oficial de **I9 Electricidad**: electricidad, aire acondicionado y albañilería para viviendas, comunidades, oficinas, locales e industrias.

## Stack

- TanStack Start (React 19 + Vite)
- Tailwind CSS v4
- TypeScript

## Desarrollo

```bash
bun install
bun run dev
```
